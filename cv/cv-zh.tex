\section*{研究概述}
\noindent
本人的研究面向\textbf{AI / 网络基础设施}，构建\textbf{测量、资源调度与安全}技术，
覆盖互联网（BGP、RPKI、DNS、Web PKI）、ISP 与运营商骨干网、
\textbf{FITI / CERNET / CERNET2} 国家级试验设施，以及从智算集群到超大规模云与
Serverless 平台的智算 / 数据中心。研究工作分为三个方向，服务于同一个目标——
\emph{让 AI / 网络基础设施看得清、调得优、守得住}：

\begin{enumerate}[leftmargin=1.8em,label=\textbf{\arabic*.}]
  \item \textbf{AI / 网络基础设施测量。}以线速、零应用改造的方式让生产基础设施可观测：
  基于 eBPF 的零代码分布式追踪（SIGCOMM'23、SIGCOMM'25、ICSE'26）；
  SRv6 探测与时延瓶颈诊断（ICNP'25、ToN'26）；可编程交换机上的流测量（TPDS'22）；
  以及面向 Looking Glass 服务、AS 商业关系与域间路由的互联网级测量（WWW'26、ToN'25、ICNP'26）。
  \item \textbf{AI / 网络基础设施资源调度。}把测量结果转化为高效、抗故障的带宽与算力调度：
  具备可用性保障的跨数据中心广域网流量工程（CoNEXT'21、ToN'22）；
  集中式网络效用最大化（ICNP'22、ToN'25）；路由代数（INFOCOM'25）；
  可编程交换机上的网内加速（INFOCOM'24、TPDS'22）；面向网络功能的 FaaS 平台（TPDS'23）；
  服务功能链部署与调度（TPDS'26）；以及面向企业云的即插即用网络管理（NSDI'27）。
  \item \textbf{AI / 网络基础设施安全。}在攻击与配置错误扩散之前发现并阻断：
  可编程交换机上的在线入侵检测，已在 ISP 生产环境运行（SIGCOMM'25、SIGCOMM'26）；
  可解释、能应对正常态漂移的异常检测（CCS'21、NDSS'23）；
  基于溯源图的 APT 检测（TIFS'22、TIFS'25）；
  Serverless 钱包耗尽（DoW）攻击检测（CCS'22、ToN'26）；
  路由与 Web PKI 安全（CCS'26、WWW'25）；以及运营商规模的配置验证（TIFS'24、CoNEXT'25、INFOCOM'26）。
\end{enumerate}
